# OpenVoctra
A basic, opensource Android vocavbulary-trainer, with training and learn functions.

I made this for my siblings which wanted a app like this without apps and with audio-feature.

Please notice, that this App is not and will not be available on the Google Play store. So you have to sideload it. Just download the APK from the releases and open it.

But Google want‘s to lock android down, so you have to do many steps to sideload apps. Please support me and the whole Community around opensource-android-Apps and visit this side: keepandroidopen.org

This update is not an OS update but an google-play-services-update. This Updates don‘t need any agreement and you cant stop it.

But: If you use an program like Waydroid, you can use install it, if you don‘t install thise services. Same for Custom-Roms like Lineage OS or Graphene OS! Or you can do !9! steps in the Developer-Options including an 24 hour wait to unlock sideloading again (more informations on keepandroidopen.org).
